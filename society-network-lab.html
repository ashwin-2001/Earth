Model & help

State

Directed weighted graph G(t) = (V, E, W). Node i: cluster c, fitness η, skill vector s ∈ ℝ⁶, reserve R, pressure P, innovation u, leverage, trust threshold. Edge i→j: weight w, flow F, capacity C, trust, age, type.

Flow (per tick)

P_i = R_i / cap_i − 0.3·φ·η_eff,i·ln(1 + w_in,i) cap_i = 5·(1 + ln(1 + w_in,i + w_out,i)) F_ij = min( C_ij , λ_i · k·w_ij·max(0, P_i − P_j)/(1 + ν_c) ) C_ij = capacity·(0.5 + w_ij) congestion_ij = F_ij / C_ij λ_i = min(1, 0.25·R_i / Σ_out demand) (cannot send > 25% of reserve) Re_i = mean congestion_i · ln(1 + k_i) / ν_c turbulent if Re_i > Re_c

Resources, states

dR_i = Σ_in F − Σ_out F + income_i − cost_i income_i = wage_c · e_i · (0.5 + 0.5·M_i) · η_eff,i · (1 + noise) cost_i = cost_c·(1 + feedback·congestion_c) + base + 0.003·k_i + δ·R_i stressed: R < stress thr. dormant: R < survival thr. for 15 ticks pruned: dormant, isolated, 80 ticks. hub: w_in > μ + 2.5σ and R > R̄

Labour matching

M_i = cos(s_i, d_c) A_i = volume · leverage_i q_i = quality / (1 + dilution·ln A_i) S_i = q_i · M_i ρ_c = min(1, |c| / Σ_{i∈c} A_i) (receptivity; congested by volume) H_i = 1 − exp(−2·A_i·S_i·ρ_c) e_i = H_i · σ(10·pen·(M_i·(1 + 0.1 ln(1 + w_i)) − thr − automation))

Edge formation (roulette over 8 candidates)

candidates: 3 global ∝ η_eff·(k+1)^α, 2 in-cluster ∝ same, 2 friends-of-friends, 1 uniform score_ij = base_j·(1 + β·cos(s_i,s_j))·(1 + θ·CN_ij)·(1 + ε·hole_j) ·(1.5 if same cluster) / (1 + d_ij/120)^γ · (1 + noise) attempts_i = rate·A_i·(1 + ½·min(2, R_i/cap_i)) / (1 + k_i/attention) accept with ρ_{c_j}·(0.25 + 0.75·S_i); reciprocate with p_recip

Edge dynamics

dw = η_w·F·trust − λ·w·m (m ×4 dormant, ×2 stressed, ×(1−0.8·remote) cross-cluster) trust += 0.02(1−trust) on successful flow; −0.03 per overload; − decay·trust; − spam term when A > 2 and S < 0.4 prune after 20 ticks with w < thr or trust < target threshold

Migration & innovation

U_i(c) = E[income | c] − cost_c(1 + fb·cong_c) + 0.05·Σ_{j∈c} w·trust − ½·stressed_c·wage_c P_move = σ(β_m·(U_i(c') − U_i(c)) − migCost·ν_c) du_i = D·Σ w(u_j − u_i)/Σw − λ_u·u_i + κ·u_i(1 − u_i) + S_i

Detection

Every tick: rolling z-score of key metrics over the window; |z| above threshold is logged. Every 10 ticks: regime classifier (stable / congested / turbulent / fragmented / monopolized), rich-club growth, echo chambers, broker capture, spam collapse, monopoly, poverty traps, innovation fronts, cascades and critical slowing down (Kendall trend of lag-1 autocorrelation and variance of detrended total flow). Shocks log recovery at +60 and +200 ticks.
